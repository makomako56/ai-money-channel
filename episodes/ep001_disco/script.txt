# ep001 ディスコ ― 「AIが混んでて使えない！」を裏で支える日本企業
# 流れ：日常の困りごと → なぜ起きる？ → 解決する技術 → その会社 → 稼ぎ方 → 数字 → 弱点 → まとめ
# 数字はすべて research.md と照合済み。出典は各スライドの下部に記載
[スライド: 01]
ひなた「先生、聞いてください！昨日、宿題をAIに手伝ってもらおうとしたら…」{困り顔}
ミライ「ふふ、宿題は自分でやるものですよ」{笑顔}
ひなた「ち、違います、相談です！それより、全然返事が来なかったんです」{困り顔}
ひなた「『ただいま混み合っています』って出て、ずっとクルクル…」{困り顔}
ミライ「ああ、ありますね。人気のAIほど、混む時間帯があります」
ひなた「AIって、混むものなんですか？お店じゃないのに」{驚き}
ミライ「実は、AIにも『お店』みたいな場所があるんです」{ドヤ顔}
[スライド: 02]
ミライ「AIは、スマホの中で考えているわけじゃありません」
ミライ「遠くにある、巨大な計算センターで考えているんです」
ひなた「えっ、私のスマホで考えてるんじゃないんだ！」{驚き}
ミライ「質問が届くと、計算センターの機械が一斉に計算して、答えを返します」
ひなた「みんなが一度に質問したら…」
ミライ「そう、レジに行列ができるのと同じです」{笑顔}
ひなた「じゃあ、レジを増やせばいいのに！」
ミライ「その通り。だから今、世界中で計算センターがどんどん作られています」
[スライド: 03]
ひなた「計算センターの機械って、何が大事なんですか？」
ミライ「頭脳にあたる計算用のチップと、記憶にあたるメモリです」
ミライ「特にAIには、ものすごく速いメモリが必要なんです」
ひなた「メモリが遅いと、どうなるんですか？」
ミライ「頭脳が、メモの読み書き待ちで止まってしまいます」
ひなた「あー…私がノートを探してる間、手が止まるのと同じだ」{困り顔}
ミライ「ふふ、いいたとえです」{笑顔}
[スライド: 04]
ミライ「そこで使われるのが、HBMという特別なメモリです」
ひなた「えいち、びー、えむ…？」{困り顔}
ミライ「メモリのチップをうすーく削って、何枚も重ねたものです」
ミライ「ビルみたいに上へ積むと、近くでたくさん読み書きできるんです」
ひなた「へぇ、薄いチップのビル！でも、そんなに薄くできるんですか？」{驚き}
ミライ「そこが今日の主役の出番です」{ドヤ顔}
[スライド: 05]
ミライ「チップを薄く削ったり、きれいに切り分けたりする機械」
ミライ「それを作っているのが、日本のディスコという会社です」
ひなた「ディスコ…？踊るほうの？」{困り顔}
ミライ「踊りません。東京にある、半導体の加工機械の会社です」{笑顔}
ひなた「聞いたことない…」
ミライ「得意技は、たった3つ。切る、削る、磨く。それだけです」
ひなた「えっ、それだけで大丈夫なんですか？」{驚き}
ミライ「それだけを極めたから、強いんです」{ドヤ顔}
[スライド: 06]
ミライ「半導体は、ウェーハという薄い円盤から作ります」
ひなた「あ、キラキラした丸いやつ！見たことあります」{笑顔}
ミライ「ウェーハに回路を作ったら、裏を削って薄くして、切り分けます」
ミライ「最後のこの仕上げを、ディスコの機械が担っています」
ひなた「料理でいうと、盛り付けの係ですね！」{笑顔}
ミライ「ふふ、そうですね。ここを失敗したら、全部台無しです」{笑顔}
[スライド: 07]
ひなた「ちなみに、私のスマホにも関係ありますか？」
ミライ「ありますよ。スマホの中のチップも、薄く削られて入っています」
ひなた「スマホが薄いのに高性能なのは、そのおかげなんだ…」{驚き}
ミライ「身近なところで、毎日お世話になっているんです」{笑顔}
[スライド: 08]
ひなた「AIが混むほど、計算センターが増えて、ディスコの機械も売れる…」
ミライ「そういうことです。では、本当に儲かっているか見てみましょう」
ミライ「ディスコの売上は、2024年3月期が約3,075億円」
ミライ「それが2026年3月期には、約4,368億円まで増えました」
ひなた「1,000億円以上も増えてる！」{驚き}
ミライ「しかも今期は、4月から9月の半年だけで約2,570億円です」
ひなた「半年で、去年1年の半分を超えちゃってる…」{驚き}
[スライド: 09]
ミライ「その半年で、売上は前の年より32%増えました」
ミライ「本業のもうけである営業利益は、48%増の約1,166億円です」
ひなた「売上より、もうけのほうが伸びてる！」{驚き}
ミライ「しかも、売上の約45%が営業利益なんです」
ひなた「それって、すごいんですか？」{困り顔}
ミライ「100円売ったら、45円がもうけ。とても高い水準です」{ドヤ顔}
ひなた「私のお小遣い帳とは、桁も割合も違う…」{困り顔}
ミライ「会社の説明でも、生成AIとHBM向けの需要が理由だと書かれています」
[スライド: 10]
ひなた「でも、機械って一回売ったら終わりじゃないんですか？」
ミライ「いいところに気づきました。ディスコは刃や砥石も売っています」{笑顔}
ミライ「削ったり切ったりすると、刃はすり減りますよね」
ひなた「あ、だから買い替えが必要なんだ！」{驚き}
ミライ「プリンターと、インクの関係と同じです」
ひなた「工場が忙しいほど、刃が売れる！うまい仕組み！」{笑顔}
ミライ「7月から9月の出荷では、機械が約6割、消耗品が約2割でした」
[スライド: 11]
ひなた「じゃあ、ディスコはずっと安泰ですね！」{笑顔}
ミライ「…そうとも限りません。弱点も見ておきましょう」
ミライ「一つは、AIへの投資が行き過ぎていないか、という心配です」
ひなた「計算センターを作るのが止まったら…」{困り顔}
ミライ「機械の注文が減ってしまいます。ブーム頼みの怖さですね」
ミライ「もう一つは為替。海外のお客さんが多いので、円高だと利益が減ります」
ひなた「円高って、日本の会社には逆風なんだ…」{困り顔}
ミライ「実際、10月から12月の売上の見通しは、7月から9月より少なめです」
ミライ「会社は、需要が弱まったのではなく、受け入れ時期と為替が理由と説明しています」
ひなた「数字の裏側まで見ないと、わからないんですね」
[スライド: 12]
ミライ「では、今日のまとめです」
ミライ「AIが混むのは、計算センターに質問が殺到するから」
ひなた「だから世界中で、計算センターが増えてるんですね」
ミライ「そこで必要な速いメモリを、薄く削って作るのがディスコの機械」
ミライ「機械と刃の両方で稼ぐ仕組みが、強さの理由です」
ひなた「AIの返事を待つクルクルの裏に、日本の会社がいたなんて！」{笑顔}
ミライ「今日の一言。『困りごとの裏には、解決で稼ぐ会社がある』です」{ドヤ顔}
[スライド: 13]
ひなた「先生、計算センターの頭脳のほうも気になります！」
ミライ「ふふ、次回はAIの頭脳を作るエヌビディアです」{笑顔}
ひなた「絶対見ます！チャンネル登録もお願いしまーす！」{笑顔}
# 注意：この動画は企業の仕組みの解説です。特定の銘柄の売買をすすめるものではありません（概要欄にも記載）
