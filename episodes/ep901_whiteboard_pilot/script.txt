# 新しいタグ（T049）：
#   [手書き: 見出し]            → 紙の上部に、ペンを持った手が見出しを書いていく
#   [絵: 絵文字 | 小さな説明文]  → 紙にイラスト（絵文字を大きく）を1つ足す。手がその位置まで動いて描く。説明文は絵の下に手書き風で出す
#   [消す]                      → 紙を新しいページにする（めくる／手で消す）
#   セリフ中の【】               → 画面下のピンクの帯に、その言葉を大きく出す
