# 仕組み：Claudeが指示・確認、Codexが実行

決定：2026-10-26（オーナー）

## 役割
| 担当 | 役割 |
|---|---|
| オーナー | Claudeとのチャットで決定・承認だけ（CP0〜CP3） |
| Claude | 指示役・確認役。Codexへの作業依頼、成果物のレビュー、パイプラインの実行、デスクトップへの保存 |
| Codex（クラウド） | 実行役。依頼に従ってコードを書き、プルリクエストを出す |

## 流れ
1. オーナーがClaudeに方針を伝える
2. ClaudeがGitHubに **Issue（作業依頼書）** を作り、`@codex` で依頼する
3. Codexがクラウドで作業し、**プルリクエスト** を出す
4. Claudeがレビューする。直しがあればPRに `@codex` で修正を依頼する
5. 問題がなければClaudeがマージする
6. Claudeがパイプラインを実行して動画を作り、出来を確認して、デスクトップの `output/` に保存する
7. オーナーがCP3で確認・承認する

## Issue（作業依頼書）の書き方
- 目的：何のための作業か
- 入力：使うファイル
- やること：箇条書き
- 完了条件：確認できる形で（例：`python pipeline/check_script.py episodes/ep000_sample` が成功する）
- 守ること：AGENTS.md のルール

## 分担の細則
- コードはCodexが書き、Claudeは直接書き換えない（レビューで依頼する）
- 台本・リサーチ・概要欄はClaudeが書く
- 動画などの大きな生成物はGitHubに入れない。Claudeが作ってデスクトップの `output/` に置く
- キャラ画像（Gemini）は当面オーナーが作り、Claudeが透過・整形する
- YouTubeへの投稿は当面オーナーが手動で行う（自動化は後で）
- デスクトップのフォルダはGitHubの写し。Claudeがマージ後に同期する
