# 動画スタイル仕様 v2

決定：2026-10-26（オーナー指示）。参考：ずんめたラボの動画。試作：`templates/prototype/page.html`（Claudeの試作。録画は `record_demo.js`）

## 1. 想定する視聴者
**活字を読むのが苦手な人**。一度に読ませるのは**10〜12文字まで**。読ませたら矢印などで次に目線を動かし、次の10〜12文字を出す。画面の全部を一気に出さない。

## 2. 1本の構成（画面の種類）
| 順 | 画面 | 中身 | キャラ |
|---|---|---|---|
| 1 | **会話シーン** | 日常の背景イラスト（部屋・教室など）＋小道具（スマホ画面など）。日常の困りごとを会話で見せる | 背景の中に立つ。ポーズや跳ねる動き |
| 2 | **目次** | 今回の内容を4〜6章。章ごとに番号＋短い見出し（10字以内）＋小さなイラスト | 左右の下 |
| 3 | **章タイトル** | 上に進行バー（今ここ▼）、中央に「第1章 ○○？」の札 | 片方が指さし |
| 4 | **解説スライド** | 左上に章タグ、右上に進行チップと出典、中央に見出し。中身はセリフに合わせて段階表示 | 左右の下 |
| 5 | （3と4を章の数だけ繰り返す） | | |
| 6 | **まとめ** | 目次と同じ並びで「わかったこと」 | 左右 |
| 7 | **次回予告・終わりの会話** | 会話シーンに戻ってもよい | |

## 3. 段階表示のルール（解説スライド）
- 1回に出す文字は10〜12字。見出しも12字以内
- 出す順番：見出し → 1つ目の要素 → 矢印 → 2つ目の要素 → … → 強調（マーカーが引かれる）
- 1つのセリフにつき、出すのは1段階まで
- 動き（0.3〜0.5秒）
  - ふわっと上がる：見出し・文
  - ポンと出る：カード・アイコン
  - 左から伸びる：矢印
  - 塗られる：マーカー（大事な言葉）
- 出したものは、そのスライドの間は残す（消さない）
- 出典は右上（左右の下はキャラで隠れるため）

## 4. 字幕
- 画面下の中央。話者の顔アイコン（丸）＋太字の白文字＋話者色の太い縁（ミライ：ネイビー、ひなた：オレンジ）
- 1行は約16字、最大2行。**台本の1セリフは32字以内**（超えたら分ける）
- 改行位置は意味の切れ目（台本に `／` で指定できる）

## 5. キャラ
- 話している方：明るく、話し始めに小さく跳ねる、口パク
- 聞いている方：少し暗く、ゆっくり揺れる
- 会話シーンでは、背景の中に全身で立つ（全身の立ち絵が必要。未作成）

## 6. 台本の書式 v2
```
[画面: 01]            画面ファイル pages/01.html を表示（1段階目まで出た状態から始まる）
[表示]                次のセリフの開始と同時に、次の段階を出す（[表示: 3] で段階番号の指定も可）
ミライ「セリフ」{笑顔}
ひなた「セリフ／改行位置」{驚き}
```
- `[スライド: NN]` は `[画面: NN]` の旧名として当面使える
- 画面は Claude が HTML で作る（`episodes/epNNN/pages/NN.html`）。段階表示する要素に `data-step="2"` などを付ける。種類は class（`up` / `pop` / `draw` / `mark`）で指定
- 画面の種類は `<body data-layout="scene|slide|title">` で指定。キャラの立ち位置は動画工場が決める

## 7. 役割
- Claude：台本、画面のHTML（中身と段階）、背景イラストの指示（プロンプト）
- Codex：画面のHTMLを段階ごとに動画にする仕組み、キャラ・字幕の合成（作業依頼02）
- オーナー：全身立ち絵と背景イラストの最初のセット（Gemini）
