# 音声工場（作業依頼01）

GitHub Actionsの `factory.yml` で実行する。Python 3.11、CPU版VOICEVOX、ffmpegを使い、Mac上でエンジンを起動する必要はない。Secretsは不要。動画・サムネ・YouTube投稿はまだ実装していない。

## Claudeからの起動と取得

mainへのマージ後：

```bash
gh workflow run factory.yml -R makomako56/ai-money-channel -f episode=ep000_sample -f stage=voice
gh workflow run factory.yml -R makomako56/ai-money-channel -f episode=ep000_sample -f stage=voice_samples
gh run list -R makomako56/ai-money-channel --workflow factory.yml
gh run watch RUN_ID -R makomako56/ai-money-channel --exit-status
gh run download RUN_ID -R makomako56/ai-money-channel -n ep000_sample-voice -D output/ep000_sample/voice
```

声サンプルはartifact名を `ep000_sample-voice_samples` に変えて取得する。artifactの保存期間は7日。新規workflowのマージ前検証用に、`codex/issue-1-voice` ブランチで実装ファイルをpushすると両ステージを実行する。手動実行と同じジョブ・コマンドを通り、mainを変更せず動作を確認できる。

## 出力と検証

- `voice`: `wav/0001.wav` … と `timeline.json`。WAVはセリフ単位の24kHz・16bit・モノラルPCM。
- `voice_samples`: No.7、九州そら、冥鳴ひまり、春日部つむぎ、四国めたんの5本のMP3。ファイル名は `キャラ名_スタイル名.mp3`。比較条件をそろえ、全員が依頼書の同じ2文を話速1.0・音高0.0で読む。
- artifactのルートを基準にWAVパスを解決する。タイムラインはセリフの配列で、`line`（台本の1始まりの行番号）、`speaker`、`text`、`expression`、`slide`（`"01"`形式。指定前はnull）、`start`、`end`（秒）、`wav`、`voice`、`envelope_fps`、`envelope`を含む。
- `envelope`はWAV先頭から1/30秒ごとのRMS音量（フルスケールに対して0〜1）。最後の端数フレームも含む。無音の間はWAVに混ぜず、タイムラインの時刻に反映する。
- 最初のセリフは0秒開始。通常は前のセリフの終了から0.25秒、スライド番号が変わった場合は0.6秒（0.25秒に加算せず置き換え）。最後に余分な間は入れない。設定は `config/style.yaml`。
- Actionsは全WAVの実際の尺、台本との一致、間、30fps包絡、無音でないことを確認する。MP3は5人分の存在、尺、ffmpegでの全体デコードを検証してからuploadする。結果はActionsのジョブサマリーにも残る。
- 合成途中で失敗した出力は公開せず、既存出力がある場合は混ぜずにエラーにする。

## 台本・設定

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s pipeline/tests -v
python -m pipeline.script_parser episodes/ep000_sample/script.txt --no-slide-check
```

通常は参照スライド画像を確認する。Actionsでは、依頼書の補足に従い `ep000_sample` に `slides/` ディレクトリがまだない場合だけ `--no-slide-check` を付ける。他の回やslides配置後は省略しない。表情の画像がnullでも、設定に定義された表情名なら受け付ける。

`config/characters.yaml` の `voice.speaker_id` が最優先。nullなら `voice.name` を `No.7（ノーマル）` のようなキャラ名＋スタイル名で照合する。両方未指定なら警告して、ミライ＝No.7（ノーマル）、ひなた＝春日部つむぎ（ノーマル）を仮に使う。明示した声が見つからないときは勝手に代替せずエラーにする。話速・音高は同ファイルの `speed` / `pitch` を使う。

`config/reading_dict.csv` は `表記,読み,アクセント位置` のCSV。読みはVOICEVOXが受け付けるカタカナ、アクセント位置は整数（平板は0）で記載する。合成前にエンジンへ登録し、不正な行は行番号付きで停止する。ファイルがない場合はヘッダーだけの空辞書を作る。Actionsのエンジンは毎回新規なので辞書は毎回登録する。

VOICEVOXのクレジットの動画・概要欄への組み込みは後続依頼で扱う。生成物は `output/` およびActions artifactにのみ保存し、コミットしない。

参考：[VOICEVOX Engine公式](https://github.com/VOICEVOX/voicevox_engine)、[GitHub artifact公式](https://github.com/actions/upload-artifact)。
