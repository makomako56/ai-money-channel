# 立ち絵の作成リスト（表情・動作）

作成：2026-10-26（Claude）。オーナーが Gemini で作成 → Claude が透過・位置合わせ・登録する。

## 作り方（共通）
1. キャラごとに**別のチャット**で作る（条件が混ざらないように）
2. 毎回、**基本画像（口閉じ）を添付**して、1回に1枚だけ頼む
3. ずれた画像は捨てて、必ず基本画像から作り直す
4. できた画像をClaudeに送る（ファイル名は付けなくてよい。何の画像かをひと言添える）

### 指示文のひな形
```
添付した画像と同じキャラ・同じ角度・同じサイズ・同じ服・同じ位置で、【変えたいこと】だけ変えて。
【固定条件】は必ず守って。他は一切変えないで。白背景、文字なし。
```
- ミライの固定条件：眼鏡をかけたまま、グレーの瞳、黒髪の一つ結び、ネイビーに金のふちのジャケット
- ひなたの固定条件：眼鏡なし、茶色の瞳、オレンジのヘアピン、オレンジのリボン、ノートとペンを持つ

## 動作（画像を作らなくてよいもの）
次の動きは、動画工場がプログラムで付ける（台本の `{表情|動き}` で指定）。
| 動き | 見え方 | 使う場面 |
|---|---|---|
| `ぴょん` | 小さく跳ねる | 話し始め（自動）、うれしいとき |
| `びくっ` | 一瞬縮んで震える | 驚き |
| `うんうん` | 2回小さく下がる（うなずき） | 納得 |
| `かしげ` | 少し傾く | 疑問 |
| `ずいっ` | 少し前に出て大きくなる | 強調、ドヤ |
| `しょんぼり` | ゆっくり下がって暗くなる | 落ち込み |
