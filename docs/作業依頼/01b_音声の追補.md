## 2. 声を人間らしくする調整項目
`config/characters.yaml` の `voice` に次の項目を追加し、`make_voice.py` で使う（なければ下の既定値）。

| 項目 | 意味 | ミライ | ひなた |
|---|---|---|---|
| `intonation` | 抑揚の強さ（intonationScale） | 1.2 | 1.3 |
| `volume` | 音量（volumeScale） | 1.0 | 1.0 |
| `pre_phoneme` / `post_phoneme` | 前後の無音（秒） | 0.05 | 0.05 |
| `pause_scale` | 句読点・「…」の間の倍率（pause_mora の長さを掛ける、上限0.5秒） | 1.4 | 1.4 |

- `config/style.yaml` の `dialogue_gap_seconds` を 0.35 にする
- Claudeが試した結果、この設定で自然さが大きく上がった

## 3. 音声エンジンの切り替え
- `config/voice_engine.yaml` を作り、`engine: voicevox | aivisspeech` を選べるようにする
  - voicevox：`voicevox/voicevox_engine` CPU版、ポート50021
  - aivisspeech：`ghcr.io/aivis-project/aivisspeech-engine:cpu-latest`、ポート10101
- 声はどちらも「キャラ名＋スタイル名」で引く（AivisSpeechのスタイルIDは大きな整数になる点に注意）
- 既定は voicevox のまま。切り替えは設定ファイルだけで済むこと
- `voice_samples` は、選んだエンジンの全話者・全スタイルを同じ2文で読み上げる
