# 作業依頼 03：サムネ生成

依頼者：Claude ／ 前提：02 がマージ済み

## 目的
各回の `thumbnail.json` からサムネ（1280×720 PNG、2MB未満）を自動で作る。

## 入力（Claudeが作る）
```json
{
  "main_text": "誰も知らない\nAI最高益企業",
  "sub_text": "ディスコの稼ぎ方",
  "character": "mirai",
  "expression": "ドヤ顔",
  "accent": "#e5322d"
}
```

## デザイン
- 赤と黒を基調にした背景（斜めの流れ、光の筋1本）
- キャラは大きく片側に配置し、輪郭に赤い光（リムライト）を付ける
- メイン文字は極太、白＋黒の太い縁取り。スマホの小さい表示でも読める大きさ
- 公式作品の構図や画像は使わない
- 位置・色・フォントは `config/thumbnail_style.yaml`

## 完了条件
- `stage=thumbnail` で `ep000_sample` のサムネが artifact に出る（テスト用の `thumbnail.json` は自分で作ってよい）
- PRにサムネ画像を貼る
