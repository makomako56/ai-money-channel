# 作業依頼 05：一括実行と結果の報告

依頼者：Claude ／ 前提：04 がマージ済み

## 目的
Claudeが1回起動するだけで、音声→動画→サムネ→（承認済みなら）予約投稿まで流れるようにする。

## やること
- `factory.yml` に `stage=all` を追加。`upload` は入力 `do_upload=true` のときだけ実行
- 各段階の前に入力チェック（台本の形式、スライドの存在、meta.json の必須項目、動画の長さ 3〜15分）
- ジョブの Summary に、動画の長さ・スライド枚数・警告一覧・アップロード結果を表に出す
- 失敗した段階がわかる終了コードとメッセージ
- 同じ回を再実行しても二重投稿しない（`upload_result.json` かYouTube側の確認で防ぐ）
- 1回の実行時間の目安を `docs/` に記録
