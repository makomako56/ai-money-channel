# 作業依頼06：サムネのデザインv2（2キャラ・デザイナー風）

決定：2026-11-03 オーナー「サムネに生徒の画像も載せて、デザイナーが作ったようなデザインで」。
見本：`templates/thumbnail_v2/ep001.html`（Claude 作。ブラウザで開くと 1280×720 の完成形。ep001 は YouTube に手動で差し替え済み）。

## やること
- `pipeline/make_thumbnail.py` の出力を、見本と同じ見た目にする（PR #19 の2キャラ対応の上に作る）
- 文字は `thumbnail.json` から差し込む。見本の対応：
  - 赤い帯（上）＝ `main_text` の1行目、白の大文字＝2行目の前半、黄色の特大文字＝2行目の後半（区切りは `thumbnail.json` に `main_text_parts` などで明示してよい）
  - 白い帯（下）＝ `sub_text` の前半、黄色のギザギザ＝数字部分（例「売上 1.4倍」）
- キャラ：先生（右・大きく）、生徒（手前・中央下）。表情は `thumbnail.json` の `expression` / `expression2`
- 文字とキャラの顔が重ならないことを、3つの長さの文字でテスト
