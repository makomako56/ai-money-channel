# 作業依頼 02：動画の組み立て（v2：HTML画面の段階表示）

依頼者：Claude ／ 前提：01b がマージ済み ／ 2026-10-26 に全面改訂（オーナーの新しい方針）
必読：`docs/動画スタイル仕様.md`、Claudeの試作 `templates/prototype/page.html`（ブラウザで開くと約19秒の動きが見られる）

## 目的
Claudeが書いた「画面（HTML）」を、台本のセリフに合わせて段階的に表示し、キャラ・字幕・音声と合わせて1本の動画にする。
見た目と動きは試作 `templates/prototype/page.html` を正とする（試作は setTimeout で動かしているが、本番は下の「決まった時刻で描く」方式にする）。

## 入力（Claudeが作る）
- `episodes/<ep>/script.txt`：書式 v2（`[画面: NN]`、`[表示]` / `[表示: N]`、セリフ、`{表情}`、字幕の改行 `／`）。旧書式 `[スライド: NN]` も `[画面: NN]` として読む
- `episodes/<ep>/pages/NN.html`：1920×1080 の画面。段階表示する要素に `data-step="N"`、動きの種類は class（`up` `pop` `draw` `mark`）。`<body data-layout="scene|slide|title">`
  - `pages/` がなく `slides/NN.png` だけの回は、PNGを1段階の画面として扱う（後方互換）
- 01b の `timeline.json`（セリフごとの開始・終了秒、音量の包絡）

## やること
1. **台本の解析を拡張**（`script_parser.py`）：`[画面]` `[表示]`、32字超の警告（40字は従来どおり上限エラー）、`／` を字幕の改行として保持
2. **画面のレンダラー**（`pipeline/render_pages.py`）
   - Playwright（Chromium）で各画面を開く。段階Nを出すときは、`data-step<=N` の要素に class `show` を付ける（試作と同じ）
   - 動きは**決まった時刻で描く**：アニメーションを止めて `document.getAnimations()` の `currentTime` を 1/30 秒ずつ進め、毎フレームを画像にする。動きのない時間は直前のフレームを使い回す（速度のため）
   - 段階を出す時刻＝`[表示]` の直後のセリフの開始時刻
   - フォントは画面のHTMLが読み込む（`fonts/` を相対参照）。読み込み完了を待ってから描く
3. **合成**（`pipeline/make_video.py`）：画面の映像の上に、キャラと字幕を重ねる
   - 字幕：仕様書4章（顔アイコン＋白文字＋話者色の太い縁、1行約16字・最大2行、`／` で改行）
   - キャラ：仕様書5章（話者は明るく・跳ねる・口パク、聞き手は暗く・ゆっくり揺れる）。表情は `{表情}`、ない表情は「通常」で代用（警告）
   - 立ち位置は `data-layout` で変える：`slide`＝左右の下（試作どおり）、`scene`＝画面中央寄りに2人並ぶ、`title`＝`slide` と同じ。位置・大きさは `config/style.yaml`
   - 立ち絵は今は腰上。あとで全身の立ち絵（別ファイル）に差し替えられるよう、キャラごとに「腰上用」「全身用」を設定で選べるようにする
   - 音声（01bのWAV）をつなぎ、BGMがあれば −24dB 程度で敷く。末尾にクレジット（「音声：AivisSpeech（まお・コハク）」など）
4. `stage=video` を `factory.yml` に追加
5. 確認用：`review-outputs` ブランチに、854×480 の低画質版（100MB未満）と、各画面の各段階の静止画（`frames/NN-S.png`）を push

## 性能
10分の動画を Actions で30分以内に作れること。超える場合は、どこが遅いかと改善案をPRに書く。
