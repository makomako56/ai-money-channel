# 作業依頼 02a：動画の組み立て（録画方式・最小版）

依頼者：Claude ／ 2026-10-27 ／ Issue #2 を軽くするため、02a と 02b に分割した。**まず 02a だけ**。
**読むのはこのファイルと、下の「参照するファイル」だけでよい。** リポジトリ全体を読まないこと。

## 方針（重要：作る量を減らす）
Claude が `tools/preview/player.html` に**動く見本**（画面の段階表示・キャラ・字幕・表情・動き・口パク・まばたき）を作ってある。
これを**ほぼそのまま使い**、「時間の決め方」と「音声」だけを本番用にする。フレームを1枚ずつ描く方式（旧 02 の案）はやめる。

## 参照するファイル
- `tools/preview/player.html` と `tools/preview/record.js`（見本。ローカルで `python -m http.server 8765` → `node tools/preview/record.js ep001_disco out.webm` で動く）
- `pipeline/make_voice.py` が出す `timeline.json` の形式（`output/<ep>/voice/timeline.json`）
- `.github/workflows/factory.yml`

## やること
1. `tools/preview/player.html` をもとに `pipeline/stage/player.html` を作る
   - セリフの開始・終了時刻を、文字数ではなく `timeline.json` の値で決める（ページを開いた時刻を0秒として、その時刻に合わせて表示を切り替える）
   - `[画面]` `[表示]` の切り替えも、`timeline.json` の時刻（次のセリフの開始時刻）に合わせる
   - 口パクは `timeline.json` の音量の包絡を使う（なければ見本どおり交互）
   - 字幕の顔アイコンは `assets/characters/<キャラ>/face/`（表情と同じファイル名、顔が中心になるよう切り出し済み）を使う。立ち絵を丸く切り抜かない（オーナー指摘：顔が中心に来ない）
2. `pipeline/make_video.py`
   - Playwright で `player.html` を開いて録画（1920×1080、30fps相当）
   - 録画と、セリフのWAVをつないだ音声を ffmpeg で合成 → `video.mp4`（H.264＋AAC）
   - 末尾に「音声：AivisSpeech（まお・コハク）」のクレジットを2秒
3. `factory.yml` に `stage=video`（voice の後に実行）
4. 確認用：`review-outputs` の `<ep>/video/` に 854×480 の低画質版（100MB未満）だけを push

## 完了条件
- `ep001_disco` で `video.mp4` ができ、低画質版が `review-outputs/ep001_disco/video/` に入る
- 音声と字幕・口パクのずれが目立たない（PRに、ずれの目安を書く）
