# Gemini への指示：会話シーンの背景（3枚）

作成：2026-10-27（Claude）。会話シーン（動画の冒頭・最後）で使う背景。1回作れば毎回使い回す。

## 作り方
- **新しいチャット**で、1回のメッセージで**1枚だけ**頼む
- 立ち絵は添付しない（人物が描き込まれるのを防ぐ）
- できた画像はそのまま Claude に送る（ファイル名は不要。どの場所かをひと言）

## 1枚目：ひなたの部屋（夜）
```
アニメ調の背景イラストを1枚描いてください。横長16:9。人物は描かないでください。
場所：夜の女子高生の部屋。窓の外に月と街の灯り。勉強机の上にノートパソコンとスマホ、本棚、観葉植物、壁掛け時計。暖かいデスクライトの光。
画面の下3分の1は床だけにして、物を置かないでください（キャラクターを立たせるため）。
文字・ロゴ・看板は入れないでください。色はやや落ち着いたトーンで。
```

## 2枚目：放課後の教室
```
アニメ調の背景イラストを1枚描いてください。横長16:9。人物は描かないでください。
場所：放課後の高校の教室。窓から夕日が差し込む。黒板（何も書かれていない）、教卓、机と椅子が並ぶ。
画面の下3分の1は床と机の脚だけにして、手前に大きな物を置かないでください（キャラクターを立たせるため）。
文字・ロゴ・掲示物の文字は入れないでください。
```

## 3枚目：夕方の街
```
アニメ調の背景イラストを1枚描いてください。横長16:9。人物は描かないでください。
場所：夕方の住宅街の通り。コンビニ、自動販売機、電柱と電線、遠くにビル。人通りはなし。
画面の下3分の1は歩道だけにして、手前に物を置かないでください（キャラクターを立たせるため）。
看板やお店の名前など、文字は一切入れないでください（実在のお店に見えないように）。
```

## うまくいかないとき
- 人物が描かれた → 「人物は一人も描かないで」と付け足して、新しいチャットでやり直す
- 文字が入った → 「看板や画面の文字も含めて、文字を一切入れないで」と付け足す
- 縦長や正方形になった → 「横長16:9の比率で」と付け足す
