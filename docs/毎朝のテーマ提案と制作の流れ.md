# 毎朝のテーマ提案 → 制作 → 承認 → 予約公開（2026-11-03 オーナー指示）

オーナーの操作は2回だけ：**朝に番号を返す**／**プレビューを見て OK を返す**。やり取りはすべて GitHub の連絡板 Issue #15。

- **2026-11-07 追記（オーナー指示）**：毎回の `thumbnail.json` に v3 の `lines`（3〜4段。4段目は下の帯）と `characters`（1人目＝ミライ・大きく右、2人目＝ひなた・手前）を Claude が必ず書く。segment の text に空白は入れない。動画工場がこの指定で青い型を作るので、手作りの thumbnail_v3.html は不要。

## 1. 毎朝のテーマ提案（定時タスク「毎朝のテーマ提案」）
- 毎朝 7:13（日本時間）に Claude が起動し、**翌日18:00公開**の動画の題材を3つ、#15 に投稿する
- 選び方：
  1. 直近24〜48時間に**ネットニュースで注目度の高い AI 関連ニュース**を探す（複数メディアが報じている、ランキング・SNSで話題、など）
  2. そのニュースの**主役の企業**を1社選ぶ。主役の企業がいないニュース（政策・研究・社会現象など）なら、**関連の近い企業**（その技術・需要で稼ぐ会社）を選ぶ
  3. 上場企業で、決算資料・IR など一次情報で数字を確かめられる会社を優先。直近に同じ会社を扱った回は避ける
- 1案ごとに書くこと：
  - 番号、ニュースの見出し（出典URL・日付）、選んだ企業と「なぜこの会社か」1行
  - **サムネ文言案**（下の「サムネの文言」に従う）と、日常の困りごと（台本の入口）1行
- 投稿の先頭は「🤖Claude：@makomako56 明日の題材を選んでください（1〜3の番号で返事）」

## 2. 番号の返事 → 制作（毎時の巡回が担当）
- オーナーが #15 に番号（例「2」）を返したら、次の巡回で Claude が制作する。作業開始時に board.md に「作業中」を書いて push し、他の巡回と重ならないようにする
- 作るもの（CLAUDE.md・docs/動画スタイル仕様.md の書式どおり）：`research.md`（一次情報のURLと取得日）、`script.txt`、`pages/`（段階表示の画面）、`meta.json`、`thumbnail.json`
- 動画工場を `stage=all`（**do_upload は false**）で動かし、review-outputs の動画・静止画・サムネを確認する
- #15 に「🤖Claude：@makomako56 承認お願いします（epXXX）」を投稿：
  - **▶ プレビューを見る**（Claude の非公開ページ。動画＋サムネ＋確認ポイント）
  - **スライド**：review-outputs の静止画を、GitHub 上で見られる画像として貼る（主要な画面6〜8枚）
  - 要点3行（長さ・数字の出典・気になる点）

## 3. OK → 予約公開
- オーナーが #15 にその回への **OK** を書いたら、Claude が：
  1. `episodes/<回>/approval.json` を作る（`approved_by: owner`、`approved_at`：OKの時刻、`publish_at`：**翌日18:00 JST**。OKが当日16:00より前で、オーナーが「今日」と書いた場合だけ当日18:00）
  2. 動画工場を `stage=upload`、`source_run_id`＝プレビューを作った実行のID で動かす
  3. 成功したら #15 に動画URLと公開日時を書く。**投稿が成功した後は、同じ回の upload を再実行しない**（二重投稿防止）
- NG（何分何秒・直す点）なら直して、もう一度プレビューを出す
- 「OK」とみなすのは、オーナー本人のコメント（先頭が「🤖Claude」「🛠Codex」でない）で、直前のプレビュー依頼に対するものだけ

## サムネのデザイン（v3・PIVOT 風）
- 見本：`templates/thumbnail_v3/ep001.html`（参考画像 ref_pivot_*.png はオーナー提供の PIVOT のサムネ）
- 角丸の太い外枠（チャンネル色の紺）、右端に縦書きのチャンネル名
- 文字は大きく、3〜4段まで。白い箱に黒文字／紺の縁取りの白文字・黄色文字。**強調語だけ色を変える**（ピンク・黄・黄緑・オレンジ）。少し斜体
- **2人のキャラを必ず入れる**。右下に顔が大きく見えるよう配置し、**画面の約3割**。表情は文言の感情に合わせる（驚き・ショック・ドヤ顔・困り顔など）
- **キャラの顔と文字を重ねない。キャラ同士の顔も重ねない**（2026-11-03 オーナー指示）。体の重なりはよい。顔の範囲は立ち絵ごとに `data-face`（画像内の座標）で持ち、見本の重なりチェック（`window.__overlaps` が空であること）で必ず確かめる。重なったら文字を小さくするか段を減らす
- 右下の隅（再生時間）に文字を置かない

## サムネの文言
- ニュースの中身から、**驚き・不安・怒り・悲しみ・期待**など思わず反応してしまう感情に働きかける言葉にする（例「AIで仕事が消える？」「売上が2倍に!?」「なぜ日本だけ…」）
- ただし**事実と違う・誇張しすぎる言葉は使わない**（数字は research.md と照合できるものだけ）。特定銘柄の売買をすすめる言葉（「今買うべき」等）は使わない
- 1段は10字前後。一番大事な言葉を一番大きく

## 注意
- YouTube の鍵（Secrets）が切れていると予約投稿は失敗する。そのときはオーナーに「鍵の更新が必要」と通知して止まる
- 実際の投稿は、この流れの「OK」があった回だけ。即時公開はしない
