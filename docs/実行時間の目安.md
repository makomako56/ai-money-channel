## 見積もり
- 録画は**動画と同じ長さ**かかる（画面をそのまま録るため）。書き出しは動画の長さの約半分
- 音声はセリフ数に比例する（119行で約6.7分）
- 10分の動画なら、stage=all で**約27分**（30分以内）
- 時間がかかりすぎる場合は、音声の並列生成が次の改善候補

## 注意
- 部品のインストール（apt）がまれに止まる。再試行するように設定済み（`factory.yml` の Install dependencies）
