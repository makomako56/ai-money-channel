# 毎日運用の構成案（スマホで選んで承認するだけ）

作成：2026-10-26（Claude）

## 1. 1日の流れ

| 時刻（日本時間） | 誰が | 何をする | スマホでのあなたの操作 |
|---|---|---|---|
| 07:30 | Claude | 定時タスクで起動。前日〜当日のAI×企業ニュース・決算を調べる | |
| 08:00 | Claude | **テーマ3案を通知**（推奨1つに印） | 「A」「B」「C」と返信 |
| 返信後 | Claude | 一次情報で調査 → 台本 → スライド8〜12枚を作成 | |
| 返信の約1時間後 | Claude | **スライドレビューを通知**（スマホで見られるページ。スライド全枚＋台本の要約＋出典） | 「OK」か「NG＋直してほしい点」 |
| NGのとき | Claude | 修正して再送 | もう一度OK/NG |
| OK後 | 動画工場 | 音声・動画・サムネを自動生成（約30〜40分） | |
| 生成後 | Claude | 完成動画をチェック（字幕・読み・数字・尺・禁止事項） | |
| チェック後 | 動画工場 | **YouTubeに予約投稿（当日18:00公開）** | |
| 完了時 | Claude | 完了を通知（動画のURL、サムネ、概要欄） | 見るだけ |

**締め切り**
- テーマの返信：12:00まで。返事がなければ推奨案で台本まで進め、スライドレビューで止めて待つ
- スライドのOK：16:00まで（18:00に間に合わせるため）。16:00を過ぎたOKは翌日18:00の予約にする
- 何か失敗したときは、その時点で通知して止まる（勝手に公開しない）

## 2. 仕組みの全体

| 部品 | 担当 | 役割 |
|---|---|---|
| 司令塔 | Claude（定時タスク） | 毎朝起動し、調査・企画・台本・スライド・チェック・通知をすべて行う |
| スマホの窓口 | Claudeアプリ | 通知を受け取り、その会話に返信する。スライドはスマホ用のレビューページで見る |
| 動画工場 | GitHub Actions | 音声（VOICEVOX）、動画の組み立て（ffmpeg）、サムネ、YouTubeへの予約投稿 |
| 工場の建設 | Codex | 動画工場のプログラムを作る。Claudeが依頼（Issue）とレビューを行う |
| 保管 | GitHub＋デスクトップ | 台本・スライド・設定はGitHub。完成動画はデスクトップの output/ にも保存（Macが起動していれば） |

**動画工場をGitHub Actionsにする理由**：Claudeの作業環境からはYouTubeやGoogleのAPIにつながらないため。GitHub Actionsはネットにつながり、Claudeから起動と結果の取得ができる。Macの電源が切れていても動く。

## 3. 動画のスタイル（参考：ずんめたラボ）

### 画面構成（1920×1080）
- 中央上にスライド（約1440×810）。左上に今日のテーマを常時表示
- 左下にミライ先生、右下にひなた。スライドの下端に少し重ねる
- 下部に字幕帯。話者ごとに色分け（ミライ：ネイビー、ひなた：オレンジ）、白い縁取りの太字
- 右下の隅に出典（スライドごと）

### キャラの動き
- 待機中：ゆっくり上下に揺れる（呼吸、2秒周期で数ピクセル）
- 話し始め：ぴょこっと小さく跳ねる
- 口パク：音声の音量に合わせて「閉じ・半開き・開き」の3段階
- まばたき：3〜5秒ごと
- 話している方は明るく少し大きく、聞いている方は少し暗く
- 表情：台本の `{笑顔}` `{驚き}` などで切り替え

### スライドの種類（1本で8〜12枚）
1. 表紙（テーマ＋企業ロゴの代わりに文字と図形）
2. 今日の問い
3. 図解：お金の流れ（誰から誰にお金が流れるか）
4. 数字：売上・利益の推移（グラフ）
5. 比較：競合や前年との比較表
6. 仕組み：なぜ強いのか
7. リスク：弱点・注意点
8. まとめ（3行）
9. 次回予告

- 1枚に伝えることは1つ。文字は大きく
- 企業の公式ロゴは使わない（文字と図形で表す）
- スライドはClaudeがHTMLで作り、画像に変換する

## 4. 作るもの（Codexに依頼する順）

| 順 | 内容 | 完了条件 |
|---|---|---|
| 1 | GitHub Actions の土台。VOICEVOXエンジンを動かし、台本から音声を作る | サンプル台本から音声ファイルができる |
| 2 | 動画の組み立て（3章のスタイル） | ep000サンプルの30秒動画ができる |
| 3 | サムネ生成 | テンプレートからサムネができる |
| 4 | YouTube予約投稿（当日18:00 JST、承認ファイルがないと動かない） | テスト動画が非公開で予約される |
| 5 | 全工程を1回で動かすワークフロー | Claudeの1コマンドで、承認済みの回が最後まで流れる |

すべてそろったら、Claudeの毎朝の定時タスクを作る。

## 5. あなたに初回だけお願いすること

1. **Codexのクラウド環境を作る**（前回の依頼）
2. **YouTube APIの準備**：Google Cloudでプロジェクトを作り、YouTube Data APIを有効化、OAuthの認証情報を作る。手順書と、認証用の小さなツールはCodexに用意させる。最後に、できた鍵をGitHubの「Secrets」に登録する
3. **声を決める**：動画工場ができたら、候補の声でサンプル音声を作ってスマホに送るので、聴いて選ぶ
4. **ひなたの画像**：Geminiで基本画像を1枚作って送る（差分はそのあと一緒に作る）
5. **通知をオンにする**：スマホのClaudeアプリの通知を許可する

## 6. 注意点

- **YouTubeの方針**：AIで量産した似たような動画は、収益化の対象外になることがある。毎回の企業・切り口を変え、あなたの一言（実務の視点）を時々入れるのが安全。AIで作った人物の映像として、合成コンテンツの申告が必要か確認する
- **金融の扱い**：特定銘柄の売買をすすめない。数字は必ず一次情報で確認し、出典を画面と概要欄に出す
- **費用**：GitHub Actions は非公開リポジトリだと月に無料枠がある（1本30〜40分なら、毎日でも枠内に収まる見込み）。超えたら有料
- **質の担保**：毎日の確認はあなたのスライドOKだけになる。最初の2週間は、完成動画もスマホに送って確認してもらう運用にし、問題がなければ外す
