# Codexへの指示（動画工場づくり）

Codexの画面で、リポジトリ `makomako56/ai-money-channel` を選び、下の枠内をそのまま貼る。
1つ目が終わってPRが出たら、Claudeがレビューして次を依頼する（あなたは何もしなくてよい）。

---

```
このリポジトリは、YouTubeチャンネル「ミライ先生のAIマネー教室」の制作リポジトリです。
あなたの担当は「動画工場」（GitHub Actions で音声・動画・サムネを作り、YouTubeに予約投稿する仕組み）を作ることです。
企画・台本・スライドはClaudeが作り、Claudeがあなたの成果をレビューします。

まず AGENTS.md と docs/毎日運用の構成案.md を読んでください。
作業依頼は docs/作業依頼/ に01〜05があり、GitHub Issue #1〜#5 と同じ内容です。

今回は「作業依頼01（Issue #1）：GitHub Actions の土台と音声生成」だけを実装してください。
- 完了条件を満たすことを、実際に Actions を動かして確認してください
- 1つのプルリクエストにまとめ、説明に「やったこと・確認方法・確認結果（ActionsのURL）」と「Closes #1」を書いてください
- 02以降はまだ着手しないでください
- 台本・スライドの中身は変えない、秘密情報はコミットしない、生成物はコミットしない
```
