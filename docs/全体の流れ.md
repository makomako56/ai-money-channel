## 1. 何を作っているか

AIで稼いでいる企業を、先生（天野ミライ）と生徒（春野ひなた）の会話で解説する、約10分のYouTube動画。
同じ内容をnote記事にもし、広告収入とアフィリエイトで収益化する。毎日投稿を目指す。

## 2. 誰が何をするか

| 担当 | やること |
|---|---|
| カワベ | チェックポイントで承認するだけ（1本あたり約20分）。初回の設定 |
| Claude | 企画・リサーチ・台本・数字の確認・概要欄・note記事・完成品のチェック |
| Codex | 動画を自動で作るプログラム（画像・音声・動画・サムネ・予約投稿） |

ClaudeとCodexは、デスクトップのこのフォルダを共有して作業する。

- あなたがClaudeに出した指示 → Claudeが `tasks/指示ログ.md` に書く → Codexが読む
- 作業の受け渡し → `tasks/board.md` の表で行う
- GitHub はバックアップ（Codexが保存する）

あなたがClaudeとCodexの間で伝言する必要はない。Codexには「指示ログとタスクボードを見て、自分の担当を進めて」と言うだけでよい。

## 6. フォルダの中身

| フォルダ | 中身 |
|---|---|
| `docs/` | この資料など、見返すための文書 |
| `tasks/` | タスクボード、指示ログ |
| `config/` | キャラ・声・デザインの設定 |
| `assets/` | キャラ画像、BGM、デザイン参考 |
| `episodes/` | 回ごとの台本・図解・音声・動画・サムネ・概要欄 |
| `pipeline/` | 自動化プログラム（Codex） |
| `output/` | 投稿前の完成動画 |

## 7. 守るルール

- 数字は必ず出典を確認する。特定の株の売買はすすめない
- 公式のアニメ・漫画画像は参考にも使わない
- YouTubeの公開は、あなたが承認した回だけ（予約投稿）
- VOICEVOXのクレジットと、アフィリエイトの「PR」表記を必ず入れる
- 会社の副業規定を確認しておく
