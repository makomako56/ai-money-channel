# サムネ用の表情・ポーズ リスト（2026-11-13 オーナー指示）

いまの表情（ミライ12種・ひなた10種）は動画用で控えめなため、サムネでは3本並べても同じに見える。
サムネで目立つ「大げさな表情・ポーズ」を足す。作り方は `docs/立ち絵の作成リスト.md` と同じ（オーナーが Gemini で作成 → Claude が透過・位置合わせ・`config/characters.yaml` に登録）。

## 頼み方
- キャラごとに**別のチャット**。毎回 **基本画像（口閉じ・腰上）を添付**する
  - ミライ：`assets/characters/mirai/original/mirai_01_normal_closed.jpg`
  - ひなた：`assets/characters/hinata/original/hinata_01_normal_closed.jpg`
- **表情だけ**のもの（★）は、これまでどおり「表情一覧シート」でまとめて頼んでよい
- **ポーズが変わる**もの（◆）は、1回に1枚ずつ頼む

### 指示文のひな形
```
添付した画像と同じキャラ・同じ角度・同じサイズ・同じ服・同じ位置で、【変えたいこと】だけ変えて。
アニメのサムネ用なので、表情はふだんより大げさに。白背景、文字なし、記号（汗・星など）も描かないで。
【固定条件】は必ず守って。
```
- ミライの固定条件：眼鏡をかけたまま、グレーの瞳、黒髪の一つ結び、ネイビーに金のふちのジャケット
- ひなたの固定条件：眼鏡なし、茶色の瞳、オレンジのヘアピン、オレンジのリボン、ノートとペンを持つ

※ 汗・怒りマーク・縦線・キラキラ・「!?」などの記号は、動画工場があとから重ねる（下の「記号」）。画像には描かせない（位置がずれると直せないため）。
